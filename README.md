# PMP Study

프로젝트 관리 개념, 주요 이론 및 PMP 연습문제 학습 사이트.

## 온라인 사용 및 GitHub

전용 저장소: https://github.com/zimsalavvim/pmp-study

GitHub Pages 주소: https://zimsalavvim.github.io/pmp-study/

GitHub Pages는 `main` 브랜치의 루트 디렉터리를 게시합니다. 변경 후 이 프로젝트 디렉터리에서 필요한 파일을 커밋하고 `git push origin main`을 실행하면 재배포됩니다. 상위 `D:/YJLIM` 저장소와 분리된 프로젝트 전용 Git 저장소입니다.

사이트는 온라인에서 접속할 수 있지만 개인 메모와 풀이 기록은 해당 브라우저의 localStorage에만 저장됩니다. 로컬 파일과 온라인 주소는 서로 다른 저장 공간이며 기기 간 자동 동기화는 없습니다. 기록 내보내기는 백업용입니다.

## 개념별 그래픽

26개 개념 설명에 자체 제작 SVG 도식 및 설명 추가. WBS 계층도, 주공정 네트워크, EVM 수치 비교, 욕구단계, 갈등 매트릭스, RACI, 의사결정나무, 누적 확률 곡선 및 칸반 보드 등을 포함합니다. 정량 도식은 명시된 학습 예시이며 실제 측정 자료가 아닙니다. 작은 화면에서는 그래픽 영역을 가로로 스크롤할 수 있습니다.

## 화면 구성

Pretendard Variable 적용. 공식 배포 CDN의 웹폰트를 사용하므로 첫 폰트 로딩에는 인터넷 연결이 필요합니다. 불러오기 실패 시 시스템 글꼴로 표시됩니다.

일일 연습문제, 개념 및 이론, 학습 계획, 참고 자료를 독립된 탭 화면으로 구분합니다. 선택한 탭의 내용만 표시하며 URL의 `#daily`, `#learn`, `#roadmap`, `#sources`로 직접 진입 및 새로고침이 가능합니다. 브라우저 뒤로 및 앞으로 가기, 방향키 및 Home/End 키로 탭 이동을 지원합니다. 모바일에서는 상단 가로 탭을 사용합니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 외부 패키지 설치나 API 키는 필요 없습니다.
일관된 브라우저 저장 환경이 필요하면 이 디렉터리에서 `python -m http.server 8080`을 실행하고 `http://localhost:8080`을 여세요.

## 포함 내용

- 26개 학습 주제: 정의, 세부 항목, 비교, 계산식, 적용 사례 및 유의사항
- 주요 이론: 터크먼, 매슬로, 허즈버그, 맥그리거, 맥클리랜드, 토머스 킬만, 조직 구조, RACI, PERT, 제약이론 및 임계사슬, EMV, 몬테카를로, ADKAR, 칸반
- 기존 주제 보강: 프로세스 그룹, 이해관계자 매트릭스, 서번트 리더십, WBS 100% 규칙, 일정 단축, EVM 예측, 위험 대응, 품질 비용, 계약 유형 등
- 개념 검색 및 분류, 개념별 확인 문제와 해설
- 자체 제작 문제 46문항의 하루 5문항 순환 출제
- 날짜별 풀이 수, 정답 수, 정답률 및 완료 현황
- 최초 답변 기록 및 변경 방지, 오답의 관련 개념 복습 목록 자동 추가
- 학습 완료, 복습 목록, 자동 저장 메모, JSON 기록 내보내기
- 조정 가능한 8주 학습 순서 제안과 공식 자료 링크

기록은 브라우저 localStorage에 저장됩니다. 브라우저·주소가 바뀌거나 사이트 데이터가 삭제되면 이어지지 않습니다. 내보내기는 백업용이며 가져오기 기능은 현재 없습니다.

## 일일 문제 운영

한국 시간(Asia/Seoul)의 날짜 기준입니다. 같은 날짜의 문제와 최초 답변은 새로고침 후에도 유지됩니다. 정답률은 답변한 문항을 분모로 계산하며, 5문항 전체 답변 시 완료로 표시합니다. 같은 브라우저에서 다음 날짜에 접속하면 새 문제 세트를 제공합니다. 페이지를 계속 열어둔 경우에는 30초 간격 및 탭 복귀 시 날짜를 확인합니다.

문제는 무한 생성이 아니라 46문항의 순환 방식입니다. 인접 날짜 간에는 중복 없이 배정하며 이후 재출제될 수 있습니다. 지난 날짜는 기록 조회만 가능하고 소급 답변은 지원하지 않습니다. 개념 창의 확인 문제는 일일 기록과 별도이며 다시 열어 연습할 수 있습니다. 서버 동기화와 푸시 알림은 없습니다.

## 근거 및 사용 범위

확인일: 2026-10-20. 공식 문서를 복제하지 않고 입문용 설명과 문제를 자체 작성했습니다. 분류는 학습 편의를 위한 것이며 ECO 세부 과업의 공식 매핑이 아닙니다.

1. [PMI PMP 개편 안내 및 최신 ECO 진입점](https://www.pmi.org/certifications/project-management-pmp/new-exam): 2026년 7월 시험 개편과 People 33%, Process 41%, Business Environment 26% 기준.
2. [PMBOK Guide 공식 소개](https://www.pmi.org/standards/pmbok): 현재 소개된 8판은 표준 학습 참고자료. 시험 범위는 ECO와 별도로 확인.
3. [공식 Scrum Guide](https://scrumguides.org/scrum-guide.html): 스크럼 항목의 역할, 이벤트, 산출물 개념 참고.
4. [프로젝트 관리란?](https://www.pmi.org/about/what-is-project-management): 프로젝트 관리 기초 참고.
5. [PMP 응시 안내](https://www.pmi.org/certifications/project-management-pmp): 학력·경력·교육 요건은 본인 조건에 맞춰 공식 확인.

이론별 PMI 참고논문, Prosci ADKAR 공식 설명 및 Kanban Guide 링크는 `theories.js`와 화면의 참고문헌에 정리했습니다. 과거 이론 참고문헌을 현재 시험의 출제 목록으로 간주하지 않습니다. 분류와 해설 및 문제는 자체 작성 자료입니다.

26개 주제는 전체 시험 대비 교재나 공식 모의시험을 대체하지 않습니다. 이 사이트의 학습 시간은 35시간 교육 이수 증빙을 제공하지 않습니다. 실제 응시를 위해서는 최신 ECO 세부 과업 대조, 인정 교육과 경력 요건 확인, 추가 학습 및 연습이 필요합니다.

## 파일

- index.html: 페이지 구조
- style.css: 반응형 화면
- content.js: 개념 및 연습문제 데이터
- theories.js: 주요 이론, 기존 개념 보강 및 이론 참고문헌
- questions.js: 일일 문제 은행
- app.js: 검색, 학습 상태, 일일 출제 및 채점, 기록, 메모, 내보내기
- daily.css: 일일 문제 및 이론 상세 화면 스타일
- tabs.js: 탭 전환, URL 해시 및 키보드 탐색
- tabs.css: Pretendard 및 탭 화면 스타일
- graphics.js, graphics.css: 개념별 SVG 도식 및 스타일
- verify-graphics.cjs: 26개 도식의 누락 및 접근성 구조 검증
- verify.cjs: 콘텐츠, 날짜 및 기록 기능 검증

## 검증

`node verify.cjs` 및 `node --check app.js` 실행. 문제 ID와 정답 데이터, 중복 출제, 최초 답변 고정, 정답률, 오답 등록, 새로고침 복원, 기존 기록 유지, 한국 시간 자정 전환, 과거 날짜 응답 제한 및 검색 검증. 로컬 HTTP 응답 200 확인. 연결된 브라우저 부재로 실제 화면 렌더링 및 브라우저 상호작용 검증은 미실시.
